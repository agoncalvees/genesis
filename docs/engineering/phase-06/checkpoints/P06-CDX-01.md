# P06-CDX-01 — Studio e CI

## Escopo e critérios

Integrar o catálogo e as quatro prévias existentes ao Studio, manter a home neutra, restringir o Studio a dev e configurar a CI localmente. A responsabilidade deste checkpoint cobre `src/studio/`, `src/routes/`, a árvore de rotas gerada, os scripts e as configurações de Vite e Playwright, os testes E2E, o workflow e a seção do Studio no README.

Os critérios são HTTP 404 por navegação direta na produção, exclusão das demonstrações do JavaScript de produção, home e smoke funcionais, testes de acessibilidade e movimento preservados, workflow sem segredos e build padrão com saída Vercel.

## Implementação

- `/studio` abre o catálogo em `/studio/catalog`, que mantém os links para `/studio/layouts/$name`. A rota pai lança `notFound()` em produção. Os imports dinâmicos das demonstrações ficam dentro dos ramos `import.meta.env.DEV`.
- `bun run test:e2e` usa o servidor Vite na porta 3000. `bun run test:e2e:prod` usa o preset Nitro `node-server` e o servidor Node em loopback na porta 3001. O preset padrão é `vercel`.
- O workflow executa o pipeline em `push` e `pull_request`, com `contents: read`. O Playwright gera relatório HTML para upload em falhas. Os quatro refs foram verificados com HTTP 200 em seus manifests oficiais. [checkout v6](https://raw.githubusercontent.com/actions/checkout/v6/action.yml), [setup-node v6](https://raw.githubusercontent.com/actions/setup-node/v6/action.yml), [setup-bun v2](https://raw.githubusercontent.com/oven-sh/setup-bun/v2/action.yml), [upload-artifact v6](https://raw.githubusercontent.com/actions/upload-artifact/v6/action.yml).
