# P02-CDX-01 — Primitivas e catálogo

1. Definir e testar os contratos das primitivas em `tests/component/`.
2. Implementar controles e sobreposições com Base UI, estilos semânticos e exportações em `src/design-system/`.
3. Compor os exemplos em `src/routes/catalog.tsx`, regenerar a árvore e executar os cinco comandos de validação.

Critérios de aceite: catálogo neutro e responsivo, tema alternável, controles operáveis por teclado, campos com nomes e erros associados e estados verificáveis por testes.

## Entrega

- Primitivas: Button, IconButton, Input, Textarea, Select, Checkbox, Switch, Field, Heading, Text, Code, Container, Stack, Grid, Card, Badge, Spinner, Skeleton e Progress.
- Componentes: Dialog, Popover, Tooltip, Tabs, Toast, EmptyState e ErrorState. A API de Toast inclui `ToastProvider` e `useToast`.
- `/catalog` reúne exemplos neutros e alterna o atributo `data-theme` do elemento `html`. A árvore de rotas foi regenerada pelo TanStack Router.
- Os controles de Field e Progress renderizam o vínculo com seus rótulos desde o HTML do servidor. Um teste de regressão verifica Checkbox, Switch, Progress e a descrição textual do campo antes da hidratação.
- Origem das dependências utilizadas: Base UI 1.9.0 e Phosphor React 2.1.10, ambas MIT e já instaladas. Referência de composição: [documentação da Base UI](https://base-ui.com/react/overview/quick-start).

## Validação

| Comando | Código de saída final | Resultado |
| --- | ---: | --- |
| `bunx biome check --write src/design-system/{index.ts,lib/cn.ts,primitives,components} src/routes/catalog.tsx tests/component/design-system.test.tsx src/routeTree.gen.ts` | 0 | 15 arquivos verificados |
| `bun run check` | 0 | 90 arquivos verificados |
| `bun run typecheck` | 0 | TypeScript sem erros |
| `bun run test` | 0 | 70 testes em 9 arquivos, incluindo 13 testes novos de componentes |
| `bun run build` | 0 | Saída local gerada em `.vercel/output` |
| `bun run test:e2e` | 0 | 9 testes. Axe, foco e largura em 360, 768 e 1440 px nos dois temas, além de movimento reduzido |
| `git diff --check` | 0 | Sem problemas de whitespace no diff |

Smoke adicional no Chromium a 360 px em servidor local na porta 3012, saída 0. Confirmou HTTP 200, alternância claro/escuro pelo botão, seleção por teclado, retorno de foco após fechar o diálogo via Escape, abertura de popover e tooltip, exibição e dispensa de toast e ação de Retry. Sem `pageerror` ou erro de console nesse fluxo.

A primeira execução E2E encontrou a porta 3000 ocupada. Na reexecução, o axe identificou nomes ausentes no HTML inicial de toggles e Progress. A correção foi validada com o teste de regressão e a suíte E2E. No E2E compartilhado, o React pode registrar divergência de hidratação em `html[data-theme]` quando o teste escreve o atributo antes da hidratação. O smoke que alternou o tema pelo controle após a hidratação não registrou esse erro. O build emitiu avisos do Rolldown sobre diretivas `use client` em dependências. O servidor local também informou ausência de `VERCEL_OIDC_TOKEN`.

Autorrevisão concluída com inspeção do diff, captura mobile no tema escuro e smoke do catálogo. Revisão independente da implementação fica com a coordenação. Este checkpoint reúne a evidência para o registro da Fase 02 em STATUS.
