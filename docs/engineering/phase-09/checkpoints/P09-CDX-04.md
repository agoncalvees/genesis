# P09-CDX-04 — Padrões de experiência (lacunas reais)

Trabalho local em `main`, sem commit, sem push e sem dependências novas. O escopo cobre as lacunas da tabela §9 de `docs/design/AUDIT-P09.md`: editorial parcial, visualização de processamento parcial, interfaces de IA ausentes, upload ausente, workspace parcial e navegação mobile parcial. Todos os componentes consomem apenas tokens semânticos e eixos existentes e são os mesmos nos quatro mundos; a variação vem da composição já existente.

## Não construído (intencional)

- **`WorkspaceLayout` não adotou `ResizablePanels`.** O layout usa `aside` com larguras fixas por breakpoint e empilha em mobile; adotar o separador mudaria o DOM e os critérios de `layouts.test.tsx`. O componente fica disponível para composição explícita.
- **`AppNav` não renderiza `SkipLink`.** O skip link continua nos layouts (`src/layouts/layout-parts.tsx`); o design system não pode importar `layouts/`. Nenhum layout foi alterado.
- Sem canvas pan/zoom nem command palette (não pedidos nesta tarefa).
