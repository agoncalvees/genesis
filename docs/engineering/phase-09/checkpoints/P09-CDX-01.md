# P09-CDX-01 — Motor de design e eixos estruturais

Implementação local em `main`. O plano cobriu o adaptador e a identidade ativa, o consumo dos tokens nos componentes e a validação dos escopos. O aceite exigiu CSS reproduzível, rejeição de contratos inválidos, contraste em todos os escopos gerados e isolamento entre dois mundos no navegador.

## Implementação

- `tools/design-engine/` isola a integração com o Google, normaliza o contrato, valida cores e fontes e gera os temas. Os comandos incluem lint, build, check, diff, importação em quarentena e promoção explícita. O CI roda `design:check` depois de `typecheck`.
- `design/DESIGN.md` preserva as cores claras e escuras de Genesis Neutral. A cor já usada para bordas interativas ganhou o token `--control-border`. O scrim mantém a mesma cor escura nos dois modos. `themes/product.css` carrega os artefatos gerados. `worlds.css` fica reservado para a próxima entrega.
- Densidade, unidade de espaço, altura mínima e raio de controles são consumidos por Button, IconButton, Field, Input, Textarea, Select, Checkbox, Switch e Tabs. Stack, Grid, Container e os layouts usam a escala de espaçamento compartilhada.
- Card, ResultPanel, Dialog, Popover, Select, Toast, EmptyState, ErrorState, Expandable e os slots dos layouts consomem os tokens de borda, elevação ou tonalidade. Dialog, Popover, Tooltip, Select e Toast preservam o escopo temático ancestral nos portais.
- Heading, Text, Code, Badge, Metric, Progress, BeforeAfter, EvidenceExcerpt e ProcessTimeline consomem a tipografia e os raios aplicáveis. Metric aceita a família monoespaçada com numerais tabulares. O helper de Phosphor aplica o peso do escopo em Select, Checkbox, Expandable e Toast.
- O CSS consome as durações e curvas de motion do escopo. StaggerGroup também consome a intensidade. O gerador inclui o perfil e os parâmetros de spring para uso pelos mundos. A preferência de movimento reduzido prevalece sobre as durações da identidade.

## Validação local

| Comando | Saída | Evidência |
|---|---:|---|
| `bun install --frozen-lockfile` | 0 | Lockfile reproduzível com Bun 1.4.5 |
| `bun run check` | 0 | Biome sem correções ou avisos |
| `bun run typecheck` | 0 | TypeScript strict |
| `bun run test` | 0 | 210 passaram, 1 teste de IA real opt-in ignorado |
| `bun run build` | 0 | Build Vercel local com Node 24 |
| `PORT=3119 bun run test:e2e` | 0 | 30 passaram no Chromium |
| `PORT=3121 bun run test:e2e:prod` | 0 | 10 passaram no build Node server |
| `bun run design:check` | 0 | CSS gerado coincide com as fontes |
| `bun run design:lint` | 0 | O lint do Google emite avisos de tokens sem referência em `components` e ignora `genesis` na exportação oficial |
| `bun run design:diff tests/fixtures/design-neutral.md design/DESIGN.md` | 0 | Sem diferenças de tokens ou regressão no lint |

Os testes cobrem ausência de `primary`, chaves repetidas, fonte desconhecida, contraste de texto, controles e dados, distância de séries, drift e escopos gerados. O Chromium mediu dois mundos sintéticos lado a lado com alturas, padding, raios, pesos e cores independentes. Também verificou a troca de tema dentro de um único mundo e o scrim do diálogo em ambos os modos. A suíte axe passou em 360, 768 e 1440 px, em claro e escuro.

Num diretório temporário, a importação válida preservou a identidade anterior e a promoção explícita regenerou o CSS. A importação inválida ficou em quarentena e retornou 1. A tentativa de promoção inválida retornou 1 e preservou a identidade ativa. A promoção de um mundo de teste gerou o escopo correspondente e passou no drift check.

Autorrevisão concluída. Revisão independente e avaliação visual humana ficam com o coordenador. Os builds exibiram avisos conhecidos do Rolldown e o Playwright exibiu o aviso de ambiente `NO_COLOR`.
