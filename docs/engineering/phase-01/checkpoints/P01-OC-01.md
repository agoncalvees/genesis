## Decisões de implementação

- `toUiState(status, hasData)` mapeia `idle -> idle`, `running -> loading`, `completed` com dado -> `success`, `completed` sem dado -> `empty`, `failed -> error` e `cancelled -> cancelled` (estado próprio, sem colapsar em `error`). O tipo `UiState` é exportado para quem renderiza os padrões de resultado.
- `normalizeError` devolve o próprio valor quando ele satisfaz `AppError` e, para qualquer outro valor, devolve `{ code: "unknown", message: "An unexpected error occurred.", retryable: false }`. A mensagem é fixa: `stack`, mensagens cruas e outros campos de valores não-`AppError` nunca vazam.
- `withCorrelationId()` é uma função sem argumentos que retorna `globalThis.crypto.randomUUID()` como `string`, para uso em logs técnicos redigidos.
- `getCapabilities(env)` lê apenas o record recebido. Strings vazias, apenas espaços e `undefined` contam como ausentes. `ai` exige `OPENROUTER_API_KEY` e `AI_MODEL_PRIMARY`; `data` exige `VITE_CONVEX_URL`. O motivo informa somente os nomes das variáveis ausentes — nunca seus valores. Nenhuma variável é lida de `process.env` ou `import.meta.env`, e o módulo não importa nada de fora de `src/core`.
